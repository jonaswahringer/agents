# Ideas

## Learning and explanation

- Top-down explanations with a Knowledge Tree-like journey into details.
- A customized teaching skill built around that journey and an improved EITMLIF variant.

## Reports and interaction

- HTML report blocks the reader can hide, restore and hand back as edits or save
  into the file. Use Notion blocks as the reference; keep the file small.
- Docchat: talk to an agent about a generated document through a reachable agent
  endpoint, building on report block edits.

## Skills to explore

- `get-it-going`: help the user get started and keep moving.
- `plan`: turn snippets, articles and paragraphs into a coherent plan.
