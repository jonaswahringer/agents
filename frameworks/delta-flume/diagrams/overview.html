delta-flume: the big picture

Many triggers, one shared triage for the loose ones, several vessels, and every vessel leaves a record.

Shapes

Outside the vessels: triggers and output.
Shared service: triage. All vessels use it; none owns it.
Vessel: one responsibility. The orange strip is its gateway (input policy: accept the unit, start when the vessel is ready).

Inside the shapes

Decision: a unit moves on only if it passes.
Agent or tool: does the work.
Exit: a unit leaves without reaching a vessel.
Kind of part: d deterministic, s stochastic, h human.

Record. Every vessel leaves a trace of source, reasoning and decision for each unit. Where it lives is up to the vessel's mechanism: a PR, the code and its git history, an issue, or a log.

The inside of one vessel (gateway, agent loop, land) is drawn in blueprint.html.
